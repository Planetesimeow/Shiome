# 002 · A phone-ready pilot / 把手机试运行准备好

**Date / 日期**: 2026-09-11
**Branch / 分支**: `feature/deploy-mobile`
**Phase / 阶段**: Phase 1 — see [the roadmap](../roadmap-v2.md)

## What changed / 改了什么

手机有了总览、作品和截图入口，截图确认后能查看作品、补内容画像和快照。登录、HTTPS、持久化、每日备份与恢复都有可执行配置。补上慢请求切换、保存失败重试和重复点击保护，演示脚本也不再清空已有库。

The pilot now has phone navigation, authenticated screenshot capture, persistent deployment and backup tools. Slow responses cannot replace another post's form; failed saves preserve edits for retry, and demo seeding refuses existing files.

## Why / 为什么

真实截图暴露了更多口径差异：账号与作品、累计与分时、净增粉与新增关注不能混用。当前目标已明确为稳定内容方向、观看与涨粉，所以清理了默认精准获客、凭横盘推限流的旧提示。文档改为维护当前事实和剩余事项，历史取舍留在 Git 和开发记录中。

Production screenshots exposed measurement boundaries that affect decisions. The current goal is repeatable content, viewing and follower growth, so the old default emphasis on commercial intent and unsupported curve-based causal claims was removed.

## What this means for you / 这对你意味着什么

手机可以在服务器配置完成后直接进入采集与复盘流程，详情先展示播放、完播和涨粉。测试使用隔离数据和模拟识别，不产生模型费用。多张续图绑定、缺失值迁移和精细同类比较仍在下一阶段，截图指南明确了目前能保存什么。

Once provisioned, the phone can handle capture and review directly. The detail view prioritizes viewing and follows. Tests use disposable data without paid model calls. Grouped captures, missing-value migration and matched comparisons remain pending.

## Notes from the buddy / 搭档的话

部署配置通过测试，和实际在日本用手机访问仍是两件需要分别验收的事。服务器购买、域名、真实模型凭据与异地恢复还未完成。预算检查也不能保证服务商账单精确封顶。现阶段保留简单的单实例架构，先用少量真实操作验证日常成本和采集质量。

Deployment tests do not establish real phone performance in Japan. Hosting, domain and credentials still need provisioning, followed by offsite recovery and a small real-use trial. Budget checks are not an exact provider billing cap.
