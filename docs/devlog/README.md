# 潮目 Shiome · Devlog / 开发日志

A running record of what is being built, why, and what it changes for the person actually
using it. Written as the work happens, not cleaned up afterwards — including the parts
that turned out to be wrong.

一份边做边写的记录：在建什么、为什么这么建、对真正使用它的人有什么影响。写于当下，
不做事后美化——包括后来被证明判断错了的部分。

---

## How this log works / 这个日志怎么运作

Each entry has five parts. The first four are written by the AI collaborator; **the last
one belongs to the creator**, who has the final word on every entry.

每篇有五个部分。前四部分由 AI 搭档写；**最后一部分属于创作者**，每篇的结论由创作者来下。

| Section | 中文 | Who writes it |
|---|---|---|
| What changed | 改了什么 | buddy |
| Why | 为什么 | buddy |
| What this means for you | 这对你意味着什么 | buddy |
| Notes from the buddy | 搭档的话 | buddy |
| **Creator's note** | **创作者的话** | **Clarence** |

Entries are written so a creator can read them straight through without needing to know
any engineering. Technical detail is there when you want it, never required to follow along.

每篇都写成创作者可以一口气读完的样子，不需要任何工程背景。技术细节在需要时可以查，
但读懂主线不依赖它们。

> Shiome is built by [Clarence Xiang](https://github.com/Planetesimeow), with an AI
> collaborator as a working buddy. The tool, the account it serves, and the judgment calls
> are the creator's; the buddy writes code and argues about trade-offs.
>
> 潮目由 [Clarence Xiang](https://github.com/Planetesimeow) 开发，AI 作为搭档参与。
> 工具、它服务的账号、以及所有判断都属于创作者；搭档负责写代码和争论取舍。
