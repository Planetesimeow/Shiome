# 数据采集指南（截图 → 上传 → 确认）

抖音创作者中心没有 API，导出文件只有"日期+播放量"两列——单视频数据只存在于页面上。
所以潮目的数据来源是**截图**：手机 App 或 PC 网页截图都行（同样的数据、不同的排版，
系统都能识别）。截图后在网页 dashboard 点「上传截图」，AI 提取成表单草稿，
**你确认/修改后才入库**——涉及决策的数字，宁可人工确认一次。

## 采集节奏（最小可行习惯：每条视频 2 张 + 每周 2 张）

| 拍什么 | 哪个页面 | 什么时候 | 喂给什么 |
|---|---|---|---|
| **单视频体检** | 单视频数据详情页（总览） | 发布后 **+24小时** 和 **约+3天** 各一张；爆发期可加拍 +1小时 | 快照 + 终态指标 + 扩散诊断 |
| **批量同步** | 作品列表 | **每周一次**，滚动截 1-2 张 | 刷新所有视频的基础指标 |
| **账号脉搏** | 数据表现（近7天）或手机端·数据中心 | **每周一次** | 账号级指标（主页访问/净增粉/作品搜索…） |

要点：

- **详情页的小时级趋势图很值钱**：第 3 天截的一张图就包含了发布以来的完整早期曲线，
  AI 会把曲线形状（台阶爬升/横盘/断崖/平滑衰减）作为"目击证词"喂给扩散诊断。
  就算错过了 +1h/+24h 的打卡，晚截一张也能补回形状信息。
- **私密视频自动跳过**：状态为"私密"的视频别人看不到，数据不作数——提取时会标出来，
  系统拒绝入库，你不用手动排除。
- **不用整理文件夹**：AI 自己识别截图是哪种页面（详情页/列表/账号级），直接传就行。
- 确认草稿时重点扫一眼：**万/亿换算**（1.2万→12000）、**百分比**、**发布时间**——
  这三类最容易识别出错；有疑问的字段 AI 会在"需复核"里主动标出来。

## 上传入口

- Dashboard 首页 hero 区「上传创作者中心截图」按钮，或右上角「上传截图」。
- 支持一次选多张；每张独立提取、独立确认。
- 手机截图传到电脑：AirDrop / 微信文件传输助手 / iCloud 均可，格式 PNG/JPG 都行。
